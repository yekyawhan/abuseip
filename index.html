How to use

Scan IP addresses or whole ranges against AbuseIPDB right here in your browser, then explore the results with charts and insights.

🚀 Run a scan

1Paste IPs or CIDR ranges (one per line) in the left box. CIDRs auto-expand to hosts.
2Paste one or more AbuseIPDB API keys (one per line). More keys = faster + higher daily limit (1000/key/day).
3Click Run scan. Watch live progress, then the dashboard appears automatically.

🎯 Score colours (0–100)

0 Clean
1-24 Low / noise
25-74 Suspicious
75-100 Malicious

🧠 In the results

  • Verdict banner + auto insights summarise the whole scan.
  • Click a stat card, pie slice, or filter chip to filter.
  • Click an IP to copy it. Click column headers to sort.
  • Export saves the filtered rows as CSV.
  • Load CSV opens a previously exported/scanned file instead of scanning.

🔒 Privacy

  • Your keys go only to this site's proxy → AbuseIPDB. They are never stored or logged.
  • Use your own keys; each free key allows 1000 checks/day.
